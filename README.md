📊 Basic Data Analysis Projects

👋 About This Repository

Welcome to my Basic Data Analysis Projects repository!

This repository contains my beginner-level Data Analysis projects using Python and its popular libraries. These projects focus on data cleaning, data manipulation, Exploratory Data Analysis (EDA), and data visualization to extract meaningful insights from datasets.

📁 Projects

🛒 1. Retail Sales Data Analysis

🎯 Objective:
Analyze retail sales data to understand sales performance, revenue trends, and business insights.

🔍 Key Activities:

📥 Data loading and inspection

🧹 Data cleaning and handling missing values

🔄 Removing duplicate records

📊 Data manipulation using Pandas

💰 Sales and revenue analysis

📅 Monthly sales trend analysis

📈 Data visualization using Matplotlib and Seaborn

💡 Skills Learned:
Data Cleaning, Exploratory Data Analysis (EDA), Pandas, NumPy, and Data Visualization.

🏃 2. Fitness Tracker Data Analysis

🎯 Objective:
Analyze fitness tracker data to understand daily activity patterns, step counts, and weight trends.

🔍 Key Activities:

📥 Data loading and preprocessing

🧹 Handling missing values

👟 Analyzing daily steps and physical activity

📉 Calculating 7-day rolling averages

⚖️ Analyzing weight trends

🔗 Exploring relationships between fitness variables

📊 Creating meaningful data visualizations

💡 Skills Learned:
Data Cleaning, Data Analysis, Pandas, NumPy, and Data Visualization.

🍔 3. Food Delivery Data Analysis

🎯 Objective:
Analyze food delivery data to understand delivery performance, delivery time, customer ratings, and the impact of traffic and weather conditions.

🔍 Key Activities:

📥 Data loading and inspection

🧹 Data cleaning and handling missing values

🔍 Identifying outliers using the IQR method

⭐ Handling missing customer ratings

⏱️ Analyzing delivery time and identifying late deliveries

🚦 Comparing delivery times based on traffic and weather conditions

📊 Creating box plots and regression plots

📈 Predicting delivery time using NumPy's polyfit()

💡 Skills Learned:
Python, NumPy, Pandas, Data Cleaning, Outlier Detection, Exploratory Data Analysis (EDA), Data Visualization, and Basic Predictive Analysis.
